# Illumio App for ServiceNow

ServiceNow scoped application (`x_illu2_illumio`) that synchronises CMDB data with the Illumio PCE through a MID Server.

## Documentation

- [Proxy configuration](docs/proxy-configuration.md): how to reach the PCE through an HTTP proxy, why `https_proxy` is ignored, and how to troubleshoot it.

The application source lives in [`15314f1ddb882700dc9fabc5ca961943/`](15314f1ddb882700dc9fabc5ca961943/) and is managed through ServiceNow Source Control. See that folder's README before editing files outside an instance.
